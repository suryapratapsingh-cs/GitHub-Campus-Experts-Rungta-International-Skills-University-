# 🚀 GitHub Campus Experts – Rungta International Skills University (RISU)

> **Build. Collaborate. Contribute. Lead.**[cite: 1, 2]

Welcome to the official repository of the **GitHub Campus Experts Chapter at Rungta International Skills University (RISU)**[cite: 1, 2]! We are a student-led technical community dedicated to empowering students through open-source software, modern developer tools, real-world project building, and technical leadership[cite: 1, 2].

---

## 🎯 Our Mission & Vision

* **Vision:** To cultivate a vibrant and inclusive developer community that empowers students to innovate, collaborate, and lead through open-source technologies[cite: 2].
* **Mission:** To bridge the gap between classroom theory and industry practice by providing hands-on experience in Git, GitHub, AI tools, Cloud Computing, and modern software development practices[cite: 1, 2].

---

## 🛠️ What We Do

We organize community-driven initiatives to help students grow as software developers and tech leaders[cite: 1, 2]:

* 🎓 **Hands-on Workshops:** Deep dives into Git, GitHub, Open Source, DevOps, AI, and Web Development[cite: 1, 2].
* ⚡ **Hackathons & Build Sprints:** Collaborative coding events to build production-ready projects in hours[cite: 1, 2].
* 🌐 **Open-Source Contributions:** Guiding students to make their first Pull Request (PR) to global open-source repositories[cite: 1, 2].
* 🏆 **Peer Mentorship:** Code reviews, career guidance, and portfolio-building sessions[cite: 1, 2].

---

## 🎁 Benefits for Members

1. **GitHub Student Developer Pack:** Get free access to $1000+ worth of premium developer tools, cloud credits, and domain names.
2. **Proof-of-Work Portfolio:** Build a verified public GitHub profile with a active green contribution graph[cite: 1, 2].
3. **Career Readiness:** Gain practical skills that make you stand out during internships and placement drives[cite: 1, 2].
4. **Global Network:** Connect with developer communities, mentors, and industry experts worldwide[cite: 1].

---

## 🤝 How to Get Started

1. **Star & Fork this Repository:** Show your support and get familiar with Git/GitHub workflows!
2. **Join Our Community:** Scan the QR code or click the join link in our WhatsApp community to stay updated on upcoming events and workshops.
3. **Make Your First Contribution:** Check out our `good-first-issue` tagged issues to start contributing!

We follow the [GitHub Community Code of Conduct](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines) to ensure an inclusive, welcoming, and safe environment for all members. Be respectful, encouraging, and collaborative!
